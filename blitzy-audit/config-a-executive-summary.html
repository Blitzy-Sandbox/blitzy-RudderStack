08 · LIMITATIONS

Where This Baseline Is Blind

Memory-safety class (CWE-119 / 787 / 125) — Go runtime is bounds-checked; would need unsafe / cgo review
Runtime DAST — no live execution, no port binding, no traffic injection
Supply-chain CVE feed — no govulncheck, no Snyk, no OWASP Dependency-Check
Exploit verification — no proof-of-concept payload constructed

These gaps are the experimental design of Config A — measured against scanner-assisted configs.
