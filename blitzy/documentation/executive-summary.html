Findings Schema

Schema

Five-Field Output

FieldSourceConstraint
file Issue component (relative path) String
line Issue line number Integer; 0 if absent
severity BLOCKER/CRITICAL → critical, MAJOR → high, MINOR → medium, INFO → low Enum: critical, high, medium, low
cwe Rule tags CWE ID; fallback rule description CWE-N or CWE-UNKNOWN
description Issue message String; max 200 chars
