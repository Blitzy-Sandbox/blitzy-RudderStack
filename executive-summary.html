06 · Onboarding

Operational Continuity

Onboarding

Reproduce This Scan in Three Commands

Install — go install github.com/securego/gosec/v2/cmd/gosec@latest
Scan — gosec -fmt=sarif -out=results-gosec.sarif ./...
Normalize — python3 scripts/normalize-findings.py results-gosec.sarif findings-config-d.json
  • Artifacts live at the repo root and inside scripts/.
  • Extend the rule-ID to CWE table in scripts/normalize-findings.py for new rules.
